الفكرة في سطرين

  • الـ Data path (الخط المتصل): بيانات وبرامج بتتنقل. الـ Control signals (الخط المنقّط): أوامر من الـ Control Unit بتقول «اقرا / اكتب / اجمع / shift».

الـ System Bus 🚌

الـ bus = طريق مشترك بين الـ CPU والذاكرة والـ I/O. فيه ٣ طرق بتتعمل بيهم كل حاجة: Address · Data · Control.

    النقط الملونة بتمشي على الـ bus المناسب — لاحظ اتجاه كل واحدة، خصوصاً الـ data في الـ READ (راجعة للـ CPU) وفي الـ WRITE (رايحة للذاكرة).

    كل bus لوحده (اضغط على التابات)

    WHERE?One-directional → CPU to memory

    الـ CPU لما يقرا أو يكتب في الذاكرة لازم الأول يحدد العنوان (address) بتاع المكان اللي عايزه — والعنوان ده بيتحط على الـ address bus. وبرضه لما الـ software تعوز تتعامل مع I/O device بتحط عنوانه عليه.

    🔹 السلايدة بتوصفه بإنه «the uppermost bus» (الأعلى في الرسمة). 🔹 اتجاهه واحد فقط من الـ CPU للذاكرة — ده من Lecture 2 (السلايدات الأولى مابتنصش على الاتجاه).

    🏠 تشبيه: عنوان العمارة والشقة — بيقولك «روح فين»، مش بيشيل حاجة.
    WHAT?Bi-directional

    الـ data bus هو اللي بينقل البيانات فعلاً بين المكونات (CPU ↔ memory ↔ I/O). لما الـ CPU يعمل fetch: بيطلّع العنوان على الـ address bus، وبعدين الذاكرة بتطلّع الـ data على الـ data bus.

    🔹 بيشتغل في الاتجاهين (البيانات بتروح للذاكرة وبترجع منها) — وده معنى «bi-directional relationship» في السلايدة.

    📦 تشبيه: شاحنة نقل — بتشيل المحتوى نفسه رايح وجاي.
    HOW?READ · WRITE · IO/M ...

    الـ control bus بيشيل مجموعة إشارات تحكم (a collection of individual control signals) بتقول إذا كانت البيانات هتتقرا للـ CPU ولا هتتكتب بره الـ CPU. السلايدة بتوصفه بإنه «eclectic collection of signals» بتتحكم في طريقة تواصل المعالج مع باقي النظام.

    🔹 خطوط READ و WRITE هي اللي بتحدد اتجاه الـ data على الـ data bus.

    🚦 تشبيه: إشارة المرور — بتقول «اقرا» أو «اكتب» والباقي بيمشي على حسبها.

    Instruction Cycle 🔄

    الـ instruction cycle = الإجراء اللي الـ microprocessor بيعدّي بيه عشان يعالج instruction واحدة. ٣ phases — اضغط على كل واحدة.

    Fetchالـ processor بيجيب (fetches / reads) الـ instruction من الذاكرة
    1. الـ processor أولاً بيطلّع عنوان الـ instruction على الـ address bus — وعنده register اسمه Program Counter.
    2. بيفعّل إشارة READ والذاكرة بتحط كود الـ instruction على الـ data bus.
    3. في آخر الـ fetch الـ CPU بيقرا الكود من الـ data bus ويخزّنه في internal register اسمه عادةً Instruction Register.
    Decodeبيحدد أنهي instruction هو جابها

    السلايدة بتقول بالحرف: «it decodes the instruction determining which instruction it has fetched». يعني الـ decode = فهم الـ instruction (إيه هي: جمع؟ تخزين؟...) من غير ما تنفّذها لسه.

    ⚠️ فخ شائع: الـ Decode مش بتنفّذ العملية. التنفيذ في الـ Execute.
    Executeبينفّذ العمليات المطلوبة للـ instruction
    1. بيعمل عملية داخلية (internally) — زي الجمع في الـ ALU.
    2. وبيدّي الذاكرة والـ I/O الـ address, data & control signals اللي محتاجينها عشان ينفّذوا الـ instruction.

    🔬 جرّب بنفسك: شغّل برنامج صغير خطوة خطوة

    ⚠️ البرنامج ده مثال توضيحي من عندي (مش في السلايدات) — الهدف تشوف الـ PC والـ IR والـ buses وهما بيتحركوا.

    READ / WRITE Timing ⏱️

    الـ timing diagram بيوريك مين بيعمل إيه ومتى على مدار الـ clock cycles. حرّك الخطوات وشوف الإشارات بتظهر.

    🧩 الإشارات الأساسية: READ = إشارة على الـ control bus بيفعّلها الـ microprocessor لما يكون جاهز يقرا من الذاكرة أو الـ I/O؛ لما تتفعّل الذاكرة بتحط الكود على الـ data bus والـ microprocessor بياخده ويخزّنه في register. WRITE = نفس الفكرة بس للتخزين (WRITE operation causes the memory to store the data).

    📝 كلمتين مصطلحات: assert = فعّل الإشارة (خليها active). deassert = ألغِ تفعيلها. (شرح عام للكلمتين).

    الـ CPU Organization 🧠

    الـ CPU هو العقل. اقلب الكروت وشوف كل جزء جواه بيعمل إيه.

    Central Processing Unit (CPU) = الدوائر الإلكترونية اللي جوه الكمبيوتر والتي بتنفّذ instructions البرنامج عن طريق العمليات الأساسية: arithmetic, logical, control and input/output (I/O) operations.

    كل المكونات الكبيرة متوصّلة ببعض بالـ system bus: الـ data bus بيتنقل عليه البيانات، والـ address bus بيتحط عليه عنوان المكان اللي الـ software عايزاه (ذاكرة أو I/O)، والـ control bus فيه الإشارات اللي بتحدد طريقة التواصل وبتتحكم في اتجاه الـ data.

    🗂️Register sectionالقسم الأول
    مجموعة registers + bus أو أي وسيلة اتصال. الـ registers اللي في الـ instruction set architecture موجودة هنا. الـ address bus والـ data bus بيتعاملوا مع القسم ده. وفيه كمان registers المبرمج مابيقدرش يوصلها مباشرة.
    📍Program Counterregister
    جزء من الـ register section. في الـ fetch، الـ processor بيطلّع عنوان الـ instruction على الـ address bus — والـ PC هو الـ register المسؤول عن ده.
    📜Instruction Registerregister
    في آخر الـ fetch الـ CPU بيقرا كود الـ instruction من الـ data bus ويخزّنه في internal register اسمه عادةً instruction register.
    ➕ALUArithmetic / Logic Unit
    بتنفّذ أغلب العمليات الحسابية والمنطقية زي الجمع والـ AND (adding and ANDing values).
    🎛️Control Unitبتتحكم في الـ CPU
    بتستلم بعض القيم من الـ register unit وبتولّد منها control signals. وبتولّد كمان إشارات الـ system control bus زي READ, WRITE, IO/M.
    🔗سلسلة التحكممين بيتحكم في مين؟
    The CPU controls the computer, the control unit controls the CPU.
    الـ CPU بيتحكم في الكمبيوتر، والـ control unit بتتحكم في الـ CPU.
    🔎 الرسمة اللي في السلايدة (CPU): جوه The Microprocessor فيه Control unit + Arithmetic logic unit + Registers. والـ CPU بيتواصل مع Primary storage (main memory) وSecondary storage ومع الـ Input والـ Output والـ Communication devices.
    ⚠️ فخ: الإشارات READ / WRITE بتطلع من الـ Control Unit مش من الـ ALU. والـ ALU شغلها العمليات بس.
    📎 IO/M: نص السلايدة طالع «IO/» ناقص الرمز (غالباً IO/M = إشارة بتفرّق بين الوصول لـ I/O والوصول للذاكرة — ده فهم عام). المهم تعرف إنها إشارة بتولّدها الـ control unit.

    شريحة الذاكرة 🧮 Memory subsystem & chip organization

    الذاكرة بتتبني من جدول (array) من الخلايا. جرّب بنفسك: اختار عنوان وشوف الـ word line بتنوّر.

    • Memory = مجموعة دوائر بتخزّن بيانات.
    • لها عدد من الـ locations، وكل word بيخزّن قيمة binary بطول ثابت.
    • عدد الـ locations وحجم كل location بيختلف من شريحة لشريحة، لكن ثابت جوه الشريحة الواحدة.
    • الذاكرة بتتنظّم كـ array: كل cell بتخزّن bit واحد، وكل row = memory word.
    • خلايا الـ row الواحدة متوصّلة بخط مشترك اسمه word line، بيحرّكه الـ address decoder اللي على الشريحة.
    ⚠️ السلايدة كاتبة «common column called word line» (column). الصح هندسياً إن الـ word line بتمر على صف واحد — الأمان في الامتحان: كل row = word والـ word line بيحرّكها الـ address decoder.

    🔬 جرّب الـ address decoder

    اضغط على أي bit من الـ address عشان تقلبه (0/1) أو اضغط على أي row:

    Locations = 2ⁿ
    Bits per word
    Total bits = locations × word
    اللي بيطلع على الـ data bus

    المحتوى اللي في الخلايا أرقام عشوائية للتوضيح بس.

    الشريحة بتتوصف locations × word-size. مثلاً 1K × 8 = ١٠٢٤ location كل واحدة ٨ bits، يعني ١٠ address lines و٨ data lines (Lecture 2).
